AstroFire: where we are and what's next

13 Nov 2026repo: AstroFire-repo/astrofire · branch main · latest commit on main39 automated tests passing

AstroFire answers Will it burn? What proves it? How sure are we? from real NASA fire tests, and says plainly when NASA has no evidence. This brief covers what works today, how we use each NASA dataset, and the steps before the professional (submission) phase.

What works today

Screens (live NASA data)

Home · Scenario check (incl. "describe your scenario" in words) · Compare (2–4 scenarios) · Gaps map · Evidence charts · Ask NASA · NASA experiments · Materials · Data quality · Design system.

Honesty built in

No probabilities. Every test links to its NASA file + row or paper. Inferred outcomes are badged. Unknown materials are labelled. "Insufficient validated experimental evidence" is shown word for word.

Not done yet

Public deployment, demo video, rehearsals, the live AI-answer test (needs an API key) and a Docker build test. The /lite backup app is ready at /lite/.

Are we using our NASA data?

All seven investigations from the team's priority list are downloaded, cleaned and validated in the pipeline. Until now only the solid-material ones appeared on screens, because the main question is "will this cabin material burn" and the data rules forbid mixing droplets, smoke and gas jets into solid-material results. That left useful data hidden. Fixed on 13 Nov: each one now has its own place in the app (new Experiments page, Scenario and Gaps), still kept separate from solid-material results.

Why the app says "not enough data"

The big PSI downloads don't add test conditions. BASS-II's 255.8 GB is mostly videos and ISS photos of the same 130 tests (about 3.6 GB per test). BASS is 152.3 GB, SAFFIRE-III 32.8 GB. NASA's own page says BASS-II oxygen was "varied below 21% by adding nitrogen".

The gap is physical. No lab in orbit runs at Moon or Mars gravity, and raised-oxygen fires are too risky with a crew aboard. So the habitat atmosphere (34% O₂, 56.5 kPa, 0.17 g / 0.38 g) has never been flown with a solid material.

What we added: 11 tests from NASA papers that are not in PSI: Saffire IV–VI on Cygnus (up to 31% O₂, down to 54 kPa; PMMA and cotton burned) and LUCI (burns in simulated lunar gravity, in air). Shown as supporting evidence; they never change a verdict. Details: docs/DATA_ACCESS.md.

Run it on your laptop

pip install -r requirements.txt
python -m pipelines.orchestration.run_all     # rebuild + validate data (~30 s)
pytest -q                                     # 39 tests
cd frontend-app && npm install --legacy-peer-deps && npm run build && cd ..
uvicorn backend.app:app                       # open http://127.0.0.1:8000/

No big downloads needed: the repo already contains all the data the app uses (about 44 MB of raw NASA files).
