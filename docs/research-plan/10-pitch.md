## 10 likely judge questions
| Question | Short answer |
|---|---|
| Is your fire model real physics? | It encodes the published trend (BASS-II: lower O₂ limits in µg, flow-dependent); values are illustrative and labelled; verdicts are transparent rules. |
| Where is the NASA data? | PSI combustion investigations (BASS-II, SAFFIRE, FLEX) + NTRS papers; every card links to its source. |
| How do you stop AI hallucination? | Verdict from rules, not the LLM; RAG answers must cite; a skeptic check flags unsourced sentences. |
| What does "confidence" mean? | Distance between your mission's conditions and the nearest tested conditions. |
| Why not just use NASA's Test 1 data? | Test 1 is 1 g; it can't tell you about microgravity or partial gravity. |
| Who would use this? | Habitat/mission engineers, safety reviewers, NASA researchers. |
| What's new vs a chatbot? | Mission-specific decision + evidence + honest confidence + gap finding. |
| How did you test it? | 10-question gold set from papers; X/10 correct. |
| What's next? | Ingest more PSI tables, add MAPTIS Test 1 data, validate with combustion experts. |
| Which AI tools did you use? | List them (see disclosure below). |
